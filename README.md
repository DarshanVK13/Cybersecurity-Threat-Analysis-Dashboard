# Cybersecurity Threat Analysis Dashboard

An interactive **Power BI dashboard** designed to analyze cybersecurity threats, identify attack patterns, monitor network activity, and visualize security incidents through interactive data visualizations.

## Dashboard Preview

![Cybersecurity Threat Analysis Dashboard](dashboard-preview.png)

## Project Overview

The Cybersecurity Threat Analysis Dashboard provides an overview of network security events and potential cyber threats. It transforms cybersecurity data into meaningful visual insights, helping users understand attack distributions, severity levels, traffic patterns, and geographical trends.

## Dashboard Features

### 1. Interactive Filters
- Year
- Quarter
- Month
- Day
- Attack Type
- Browser

### 2. Key Performance Indicators (KPIs)
- Total Packet Length
- Total Attacks
- Average Anomaly Score
- High Severity Attacks
- Unique Source IPs

### 3. Data Visualizations

| Visualization | Purpose |
|---|---|
| Attack Type Distribution | Analyzes DDoS, Malware, and Intrusion attacks |
| Severity Distribution | Compares High, Medium, and Low severity attacks |
| Log Source Analysis | Compares Firewall and Server logs |
| Action Taken | Analyzes Blocked, Ignored, and Logged events |
| Yearly Attack Trends | Tracks attacks over time |
| Protocol Analysis | Examines ICMP, UDP, and TCP traffic |
| Year & Attack Type | Compares attack categories across years |
| Operating System Analysis | Analyzes attacks across different operating systems |
| Geographical Distribution | Visualizes security events by geographical location |
| Traffic Analysis | Examines trends across time, severity, and traffic type |

## Technologies Used

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Visualization
- Data Cleaning and Transformation

## Key Insights

The dashboard provides insights into:

- Distribution of different cybersecurity attack types.
- Comparison of attack severity levels.
- Identification of frequently targeted operating systems.
- Analysis of network protocols and traffic patterns.
- Trends in cybersecurity incidents over time.
- Geographical distribution of potential threats.
- Comparison of security actions taken against detected attacks.

## How to Use

1. Clone or download this repository.
2. Download and install Microsoft Power BI Desktop.
3. Open the `.pbix` file.
4. If prompted, update the dataset source path.
5. Refresh the data to load the dashboard.
6. Explore the dashboard using the available filters and visualizations.

## Project Objective

The primary objective of this project is to demonstrate the application of business intelligence and data visualization techniques in cybersecurity analytics.

It showcases how raw security data can be transformed into interactive dashboards for identifying trends, understanding attack patterns, and supporting data-driven security analysis.
